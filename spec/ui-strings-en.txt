3316	Welcome to the Caudiok IntelliAssistant!
3317	The Caudiok IntelliAssistant is a step by step guide that helps you to perfectly restore and optimize the sound of your music, before you record it onto CD.
3318	Track selection
3319	Please select the desired music files. Caudiok supports music files in the Wave and MP3 formats (.wav or .mp3).
3320	Category
3321	Please state, whether the individual Tracks have originally been taken from audio cassette, vinyl record or CD. Caudiok will use this information to auto-generate the best possible effect settings. Tracks taken from CD will not be restored which automatically decreases processing time. If you do not have any information about the original source medium, then you must not fill in this field.
3322	Pause between the Tracks
3323	The pause between two individual Tracks is set to a default value of 2 seconds. You can manually change this to a value between 0 and 4 seconds. To do this, click on the Pause column and input the desired value via your computer keyboard.
3324	Restoration
3325	The IntelliAssistant tests the Tracks for noise crackles and clicks. Then it selects the best possible values for restoration. The analysis is also based upon the categories that were preset under point 3.
3326	Sound Optimization
3327	The IntelliAssistant tests each Track for optimum level and density of sound. Use this option to increase the average level of a Track. If a wide dynamic range is part of the musical character of a recording (e.g. classical music), then you should not use this effect.
3328	Using additional effects
3329	In addition, each Track can individually be processed with effects. You could e.g. freshen up Track 1 by slightly using the Stereo Spread effect, while you activate Vari Speed and Reverb for the next Track. Caudiok automatically memorizes your effect settings. An effect can be activated by using the On/Off switch on its left side. Its intensity can be controlled via its fader. However, if you have already activated Automatic Restoration (point 5) and Sound Optimization (point 6), then the effects used for these processes will not be available for manual settings, as they have already been activated and set automatically.
3330	Defining Track length / Fade in and out
3331	The Waveform display shows a graphic waveform of the Track that is currently selected in the Track list. Here you determine where the Track starts and ends and set a possible fade in or fade out. To change the beginning of the selected Track, drag the green Start Marker (the lower dot on the left side) with the mouse to determine a new start position. You can use the red End Marker (the lower dot on the right side) to determine the end of the audio file in a similar fashion. Use the mouse to drag the dot to the desired end position. By using the Fade in and Fade out Markers you can gradually increase (fade in) and/or decrease (fade out) the volume of the currently selected Track within a definable time frame at the beginning and at the end of the audio file. To fade in a Track, drag the green Fade in Marker (the upper dot on the left side) to the right. If you want to fade out a Track, drag the Fade out Marker (the upper red dot} to the left until the fade out has the required length.
3332	Surround Sound
3333	By using the Surround module, you can convert a normal stereo recording into a Surround recording with spatial sound characteristics, which can still also be played back via a normal stereo system. Switch on the Surround section. Use the Surround level fader at the bottom left of the Surround section to distribute the volume level between the front and rear speakers. Then drag the individual speaker symbols to positions that correspond to the desired or available speaker positions of your ‘real’ HiFi system. The Surround settings do always apply globally to all Tracks in the Track list.
3334	Edit Mode
3335	If you want to record individual unchanged Tracks onto CD (no restoration, no sound editing), you can right-click onto the corresponding Track number in the Track list. The color of the Track number changes from red to green and the corresponding file becomes available for recording onto CD-ROM without further processing. Please do note however, that all effect settings as well as fade-ins and -outs that you might have defined for this Track will be ignored as no processing has taken place!
